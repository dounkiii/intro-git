# CCNA Quest 🎮

**普通に勉強しても頭に入らない人のための、ゲーム感覚で学べるCCNA(200-301)学習Webアプリ。**

インストール不要。`index.html` をブラウザで開くだけで遊べます。進捗はブラウザ内（localStorage）に自動保存されます。

## 遊び方

このフォルダの `index.html` をダブルクリックしてブラウザで開くだけ。
サーバーもネット接続も不要です（すべてローカルで動作）。

## 4つの学習モード

| モード | 内容 |
|--------|------|
| ❓ **クイズチャレンジ** | CCNA 6領域の4択問題。連続正解でコンボが繋がり、XPが増えます。領域別 or ランダム出題を選べます。 |
| 🧮 **サブネット道場** | ネットワークアドレス・ブロードキャスト・ホスト数を求める問題を**無限に自動生成**。CCNAの得点源であるサブネッティングをひたすら反復できます。 |
| 🃏 **フラッシュカード** | 重要用語をカードでめくって暗記。タップで裏返して意味を確認。 |
| 🚪 **ポート&プロトコル** | プロトコル名とポート番号を線で繋ぐマッチングゲーム。頻出のポート番号を体で覚えます。 |

## ゲーム要素（続けたくなる仕組み）

- **XP & レベル** — 正解やクリアでXPが貯まり、レベルアップ
- **コンボ** — クイズで連続正解するほどXPボーナスが増加
- **連続学習ストリーク** 🔥 — 毎日開くと日数が伸びる
- **実績バッジ** — 「10連続正解」「全領域制覇」など10種類の解除要素

## カバーする出題領域（CCNA 200-301 ブループリント準拠）

1. ネットワーク基礎（20%）
2. ネットワークアクセス（20%）— VLAN / トランク / STP / EtherChannel / 無線
3. IPコネクティビティ（25%）— ルーティング / OSPF / FHRP / IPv6
4. IPサービス（10%）— NAT / DHCP / NTP / SNMP / Syslog / QoS
5. セキュリティ基礎（15%）— ACL / Port Security / AAA / DHCP Snooping
6. 自動化・プログラマビリティ（10%）— SDN / REST API / YAML / IaC

## ファイル構成

```
ccna-quest/
├── index.html   … 画面レイアウトとスタイル
├── data.js      … 問題・用語・ポート表などの学習データ
└── app.js       … ゲームロジック（XP/レベル/各モード/保存処理）
```

問題を追加・修正したいときは `data.js` の `QUIZ_BANK` / `FLASHCARDS` / `PORTS` を編集するだけです。

## 進捗をリセットしたいとき

ブラウザの開発者ツールのコンソールで次を実行します:

```js
localStorage.removeItem("ccna_quest_save_v1"); location.reload();
```
