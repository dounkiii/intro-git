# CCNA Quest 🎮

**普通に勉強しても頭に入らない人のための、ゲーム感覚で学べるCCNA(200-301)学習Webアプリ。**

インストール不要。`index.html` をブラウザで開くだけで遊べます。進捗はブラウザ内（localStorage）に自動保存されます。マスコット「パケットン」と一緒にネットワークの世界を冒険しよう。

## 8つのモード

| モード | 内容 |
|--------|------|
| 💘 **恋活モード** | Pairs/タップル風のマッチングアプリ「NetMatch」で、CCNAエンジニアの女の子と恋を実らせる**恋愛シミュレーション**。プロフィールをスワイプして**いいね→マッチ→チャット→デート**へ。チャット中のCCNAトーク（クイズ）に正解すると**好感度が上がり**、しきい値を超えるとデートに進み、告白でエンディング。全5人のヒロインはそれぞれCCNAの得意分野を持つ（ルーティング/スイッチング/セキュリティ/基礎/自動化）。キャラの立ち絵と表情差分はすべてSVGで描画。 |
| 🗺️ **アドベンチャー** | パケットンを操作して分野ごとのモンスターと**問題バトル**。正解で攻撃、ミス・時間切れで被ダメージ、素早い正解は**クリティカル**💥。ボスを倒すと最大HPが増え、次の章が解放されるRPGモード。 |
| 📝 **模擬試験** | 本番同様の**制限時間・リニア形式（前に戻れない）**。1000点満点に換算し合否判定、**分野別スコアバー**と間違えた問題の復習を表示。 |
| ⚡ **サブネット・ラッシュ** | テトリス/ぷよ風の**タイムアタック**。制限時間内に高速でサブネット問題を解き、正解で時間回復＆コンボ、5問ごとに速度が上がる緊迫モード。 |
| ⌨️ **コマンド道場** | 本物そっくりの**Cisco IOS CLIシミュレータ**。モード遷移（enable → configure terminal → interface …）を再現し、略記（`conf t` / `int g0/0` / `no shut`）にも対応。6シナリオ。 |
| 🎯 **クイズ** | **初級〜本番レベル**を選んで4択演習。複数選択問題・図解問題あり。コンボでXPアップ。 |
| 🃏 **フラッシュカード** | 重要用語をめくって暗記。 |
| 🚪 **ポート&プロトコル** | プロトコル名とポート番号を繋ぐマッチングゲーム。 |

## ゲーム要素（続けたくなる仕組み）

- **XP & レベル** — 正解やクリアでXPが貯まりレベルアップ
- **コンボ** — 連続正解でXPボーナスが増加、画面に演出
- **連続学習ストリーク** 🔥 — 毎日開くと日数が伸びる
- **HP制バトル / クリティカル** — アドベンチャーのドキドキ感
- **実績バッジ18種** — 「全章クリア」「模擬試験合格」「IOSマスター」「初恋成就」「全員攻略」など
- **恋活の好感度システム** — CCNAクイズの正解で好感度が上がり、ストーリーが進む

## コンテンツ（CCNA 200-301 ブループリント v1.1 準拠）

- **問題64問**（初級40／中級13／本番11・複数選択・図解つき）
- 6出題領域を比率に沿ってカバー：
  1. ネットワーク基礎（20%）
  2. ネットワークアクセス（20%）— VLAN / トランク / STP / RSTP / EtherChannel / 無線 / CAPWAP
  3. IPコネクティビティ（25%）— スタティック / OSPF / DR選出 / FHRP / HSRP / IPv6
  4. IPサービス（10%）— NAT / PAT / DHCP / NTP / SNMP / QoS
  5. セキュリティ基礎（15%）— ACL / Port Security / AAA / TACACS+ / DAI / DHCP Snooping / WPA3
  6. 自動化・プログラマビリティ（10%）— SDN / REST API / JSON/YAML / Ansible

## 図解・キャラクター

すべて**インラインSVGで描画**（外部画像なし）。マスコット「パケットン」、分野ごとのモンスター、ネットワークトポロジ図・OSIモデル図などをコードで生成しています。

## ファイル構成

```
ccna-quest/
├── index.html   … レイアウトとスタイル、各モードの画面
├── data.js      … 問題・用語・ポート表・実績・試験情報
├── art.js       … パケットン/モンスター & ネットワーク図解(SVG)
├── faces.js     … 恋活ヒロインの立ち絵ジェネレータ(アニメ風SVG・表情差分)
├── app.js       … 状態管理・XP/レベル・クイズ・フラッシュ・ポート・保存処理
├── battle.js    … アドベンチャー/バトルエンジン
├── rush.js      … サブネット・ラッシュ
├── exam.js      … 模擬試験
├── cli.js       … コマンド道場（IOSシミュレータ）
└── love.js      … 恋活モード（マッチングアプリ + チャット + ストーリー）
```

- 問題を追加：`data.js` の `QUIZ_BANK`
- コマンドシナリオ：`cli.js` の `CLI_SCENARIOS`
- ヒロイン・ストーリー：`love.js` の `HEROINES`（各ヒロインの `route` 配列にセリフ・選択肢・クイズ・デート・エンディングをデータで記述）

## 注意

問題・合格ライン（約825/1000は非公式の目安）・試験形式は**学習用の参考値**です。受験前に最新の公式情報もご確認ください。

## 進捗をリセットしたいとき

ブラウザの開発者ツールのコンソールで：

```js
localStorage.removeItem("ccna_quest_save_v1"); location.reload();
```
